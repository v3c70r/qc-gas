## 1. 产品是什么

**Essence Québec**（`https://qgu.io/qc-gas/`）— 面向魁北克司机的**地图优先**油价查询 Web 应用（可安装 PWA）。

- 纯静态：Vanilla ES modules + Mapbox GL JS + Vite → GitHub Pages（自定义域 `qgu.io`）
- 数据源：魁省 **Régie de l'énergie** 官方 GeoJSON（`regieessencequebec.ca/stations.geojson.gz`）+
  **官方每周 Bulletin PDF**（零售毛利/区域均价）；GitHub Actions 抓取并提交回仓库
- 规模（2026-10-04 实测）：**2 461 个站点**（1 条无效坐标被前端排除）、18 区、三油品；
  regular **170.9 / 中位 192.9 / 242.9**；快照 `generated_at` 15:55Z
- 多语言：法语（默认）/ 英语 / 简体中文；无后端、无账号、无追踪、无广告

## 3. 优势（为什么魁省司机愿意用）

1. **地图上直接看到价格 + 筛选真实作用到地图**——Protégez-Vous 点出官方平台"无法筛选、只能逐个 hover"（最硬差异）。
2. **官方"贵不贵"口径齐全**：Régie 自己发布的每周零售毛利 + 我们自算的站级中位/分位（#49/#34）。
3. **打开即用、无广告、可安装**：竞品 App 近 50 条评论里 11–13 条在骂广告；我们免安装可用也能装主屏。
4. **数据诚实性成为资产**：无合成/外推、覆盖门控、离线标注"最后同步"、无效坐标不冒充站点、新鲜度可见、卡片与快照一致、
   **个人数据可导出自持**（#57）。
5. **没有后端也能做决策工具**：搜索/收藏/关注/排行/油费/加油日志/站级基准/距离排序 + 三语 + 零运维。

## 4. 劣势 / 技术债 / 数据限制（本轮核对）

| 类别 | 问题 | 影响 |
|------|------|------|
| 数据（本日提案） | **个人引用的键会静默失效**：`js/favorites.js` 的 `stationId()` 用 `name\|address\|postal_code` 文本键（坐标仅作兜底），而官方会改站名/地址；`js/watch.js` 对"找不到的站"直接 `continue` + 持久化 `kept` → **静默清理关注项**，收藏则静默失去星标。**实测（仓库内快照 diff）30 天有 27/2466 = 1.09% 的键消失，其中 12 个（44%）坐标仍在（纯文本改动，可用坐标救回）**；14 天为 0.45%（11 个中 5 个可救回） | 5 收藏 + 3 关注 ≈ 8 个个人引用 → 约 **8.7%/月**的期望失联（≈ 一年内 65% 概率至少丢一个）；而且**没有任何提示**。这与我们刚强化的"个人层"（#14/#29/#31/#57）直接冲突 |
| 数据 | **抓取投递是新鲜度天花板**：cron `*/15`、计划 36 槽/天；近 3 天实测 **17 次提交 / 3 天 ≈ 5.7 次/天**（中位间隔 **260 min ≈ 4.3 h**） | 应用里价格最坏可到 4–6 小时前；新竞品 *infoEssence* 宣称"每 10 分钟更新"（§8）→ 差距在扩大（基础设施议题，交 owner 决策） |
| 数据 | `update-profile.json` 仅 **51 个样本 / 20 个小时**（≈11/天） | 用户可见的"何时变价"洞察仍不可做（阈值见 §11） |
| 数据 | 站点级历史 180 天保留、无月 rollup；17 天 801 KB（≈+45 KB/天 → 180 天 ≈ 8 MB） | 1A 对站点不可达；盯 `check_data_size.py` 40 MB 预算 |
| 数据 | 上游无站点 ID（坐标是唯一较稳定的身份：坐标键流失率 **0.61%/30 天**，比文本键低近一半）+ 无单站更新时间 | 见本表首行；"这个价几点报的"仍答不了 |
| 功能 | 加油日志只有**当月**统计（`computeMonthStats`）；无分享/深链（URL 无法表达内容）；无深色模式；列表项是 div（键盘无法从列表打开站点） | 见 §10，未占本日额度 |
| 工程 | 无前端单元测试（只有 E2E） | 重构风险 |

## 6. 上游数据实测（2026-09-17 完成，避免重复调研）

- 站点 GeoJSON 属性只有 `Name, brand, Status, Address, PostalCode, Region, Prices[{GasType, Price, IsAvailable}]`：
  ❌ 无站点 ID、❌ 无 city、❌ 无单站更新时间、❌ 无服务设施；`IsAvailable=false` ⟺ 价格为空。
- metadata 的 `excel_url` XLSX 字段与 GeoJSON 相同 → 无收益，不接入。
- 区名匹配（2026-10-03 核对）：`js/regie.js` 的 `normalizeText()` 能匹配周报的 en dash/无重音写法；
  只有 `Municipalités hors MRC \ CMM`（**1 个站点**）无对应行 → 预期行为。

## 9. 本轮提案（已建 issue）

**个人引用不再静默失联：收藏/关注改以坐标为主键（含一次性迁移与"找不到"提示）** → issue **#59**（`pm-proposal`）。
理由：实测 30 天有 1.09% 的站点文本键消失（44% 只是改名/改地址、坐标仍在），而关注列表会**静默清理**、收藏会静默失效；
用户刚被鼓励积累并备份这些数据（#29/#31/#57），却在无声中丢引用。修法便宜：坐标键（`js/history.js` 已有约定）+ 旧键兜底 + 一次性幂等迁移 + 找不到时显式提示。

## 10. 已评估但不建议（本轮，避免重复提议）

- **"绕路盈亏平衡 / 真实成本排序"**：本轮用 255 个采样点量化后**否决**——最近站与 ≤5 km 最便宜站的价差**中位 0.00¢**，
  净收益 > 0.10$ 的只有 40%，中位净收益 0.00$，而模型（直线×2）已偏乐观；现有"价格 + 距离列 + 距离排序（#50）"已足够用户自己权衡。
- **加油日志只有当月统计**（`computeMonthStats`）：真实且有价值（配合 #57 的长期备份），但属小改 → 列为下一候选。
- **深色模式**（仅 1 条评论明确要求，外观层）、**分享/深链**（无直接用户证据）、**列表键盘可达/a11y**（受众有限）。
- **站点级 1A rollup / 月粒度降采样**：先看体积与价值（§4）。
- **接入每日 `composantes`（每 MRC 一个 PDF）或 `rqe.pdf`**：成本/增量收益不划算 → 不接入。
- **改抓取触发频率**：基础设施议题，交 owner 决策（§11）。
- **变价时段洞察**：样本 51 条，统计不可靠（阈值见 §11）；**沿途/路线加油**：需 Mapbox Directions（计费）；
  **per-city SEO 落地页**：需 prerender/多页构建 → 暂缓。
