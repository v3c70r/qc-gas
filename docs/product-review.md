## 1. 产品是什么

**Essence Québec**（`https://qgu.io/qc-gas/`）— 面向魁北克司机的**地图优先**油价查询 Web 应用（可安装 PWA）。

- 纯静态：Vanilla ES modules + Mapbox GL JS + Vite → GitHub Pages（自定义域 `qgu.io`）
- 数据源：魁省 **Régie de l'énergie** 官方 GeoJSON + **官方每周 Bulletin PDF**（零售毛利/区域均价）；GitHub Actions 抓取并提交回仓库
- 规模（2026-10-06 实测）：**2 457 个站点**、18 区、三油品；regular **170.9 / 中位 192.9 / 242.9**；快照 `generated_at` 15:55Z
  （站点总数一个月内 2466 → 2461 → 2457）
- 多语言：法语（默认）/ 英语 / 简体中文；无后端、无账号、无追踪、无广告

## 3. 优势（为什么魁省司机愿意用）

1. **地图上直接看到价格 + 筛选真实作用到地图**——Protégez-Vous 点出官方平台"无法筛选、只能逐个 hover"（最硬差异）。
2. **官方"贵不贵"口径齐全**：Régie 每周零售毛利（#49）+ 站级中位/分位（#34）。
3. **打开即用、无广告、可安装**：竞品 App 近 50 条评论里 11–13 条在骂广告。
4. **数据诚实性 + 个人数据自持**：无合成/外推、覆盖门控、离线标注、无效坐标不冒充、卡片与快照一致、导出/导入（#57）。
5. **没有后端也能做决策工具**：搜索/收藏/关注/排行/油费/日志/基准/距离排序/区域即范围，全部本地；三语；零运维。

## 4. 劣势 / 技术债 / 数据限制（本轮核对）

| 类别 | 问题 | 影响 |
|------|------|------|
| 功能（本日提案） | **加油日志只有一个口径：当月**。`js/fillups.js` 的 `renderFillupsPanel()` 固定调用 `computeMonthStats(getFillups(), historyData)`；`stats.count === 0` 时汇总区显示"暂无加油记录"，而下方列表仍列出全部历史条目 → **每月 1 号起，老用户会看到"暂无加油记录"+ 一串记录**；累计节省（#29 的核心卖点）也随之归零重算 | 日志的价值是"我到底省了多少/花了多少"，现在**无法看到今年/全部**；也浪费了 #57 刚刚建立起来的长期留存与备份能力；记账/报销类用户无法把数据带走 |

## 6. 上游数据实测（2026-09-17 完成，避免重复调研）

- 站点 GeoJSON 属性只有 `Name, brand, Status, Address, PostalCode, Region, Prices[{GasType, Price, IsAvailable}]`：
  ❌ 无站点 ID、❌ 无 city、❌ 无单站更新时间、❌ 无服务设施；`IsAvailable=false` ⟺ 价格为空。
- metadata 的 `excel_url` XLSX 字段与 GeoJSON 相同 → 无收益，不接入。
- 区名匹配（2026-10-03 核对）：`normalizeText()` 能匹配周报的 en dash/无重音写法；只有 `Municipalités hors MRC \ CMM`（1 站）无对应行。

## 7. 关键实测数据（供后续提案引用）

- **加油日志口径（本轮，代码级）**：`computeMonthStats(fillupsList, historyData, now)` 以 `now` 的月份过滤；汇总区三分栏 = 本月支出 / 实付均价 / 累计节省；
  `renderFillupsPanel()` 在 `stats.count === 0` 时显示 `fillupNoRecords`（"暂无加油记录"），而列表用 `getFillups()` 输出**全部**条目 ⇒ 每月 1 号出现"无记录 + 有记录"的自相矛盾。
- **区域 × 半径陷阱（2026-10-05 实测，已由 #60 修复）**：半径模式下选远处区域恒为 0（Gaspésie 0/58、Abitibi 0/77、Côte-Nord 0/59、BSL 0/99、Saguenay 0/157；Québec 市中心亦然）。
- **站点键流失（2026-10-04）**：30 天文本键消失 **27/2466 = 1.09%**（12 个坐标仍在）；坐标键 0.61%；14 天 0.45%。
- **绕路盈亏平衡（已否决）**：255 采样点，最近站 vs ≤5 km 最便宜站价差中位 **0.00¢**、净收益 >0.10$ 仅 40%、中位净收益 0.00$（模型偏乐观）。
- **官方周报数据**：`data/regie-margin.json` 当前为 2026-09-21→28 周；**17 区中 10 个 regular 毛利为负**。
- **抓取投递**：≈5 次/天（中位间隔 ≈260 min）；`update-profile` ≈60 样本 / 20 小时。
- **价格水平 / 体量**：regular 170.9 / 中位 192.9 / 242.9；站点历史 18 天 843 KB；站点总数 2457。

## 9. 本轮提案（已建 issue）

**「Mes pleins」期间口径 + CSV 导出：看到今年/全部的支出与累计节省** → issue **#62**（`pm-proposal`）。
理由：日志存在的意义是"我到底省了多少"，而现在**只有当月**（每月 1 号还会显示"暂无加油记录"却列出历史条目）；
#57 刚让日志可以长期保存/备份，却看不到长期结论，也不能导入表格做记账——而 GasBuddy/Fuelio 这类同类工具都把 CSV/终身统计当作核心。

## 10. 已评估但不建议（本轮，避免重复提议）

- **首次访问的"选择你的区域"引导**：真实痛点（默认全省列表对非 Montréal 用户无意义），但 #60 之后区域选择已经好用，
  且自动猜测地区需要 IP/地理信息（无后端）→ 记为后续小项，不与本日提案争额度。
- **深色模式**（仅 1 条评论明确要求，外观层）、**分享/深链**（无直接用户证据）、**列表键盘可达/a11y**（受众有限）。
- **站点级 1A rollup / 月粒度降采样**：先看体积与价值（§4）。
- **"绕路盈亏平衡 / 真实成本排序"**：已用 255 采样点量化后否决（§7）。
- **接入每日 `composantes`（每 MRC 一个 PDF）或 `rqe.pdf`**：成本/增量收益不划算 → 不接入。
- **改抓取触发频率**：基础设施议题，交 owner 决策（§11）。
- **变价时段洞察**：样本 ≈60 条，统计不可靠（阈值见 §11）；**沿途/路线加油**：需 Mapbox Directions（计费）；
  **per-city SEO 落地页**：需 prerender/多页构建 → 暂缓。
