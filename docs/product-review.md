## 1. 产品是什么

**Essence Québec**（`https://qgu.io/qc-gas/`）— 面向魁北克司机的**地图优先**油价查询 Web 应用（可安装 PWA）。

- 纯静态：Vanilla ES modules + Mapbox GL JS + Vite → GitHub Pages（自定义域 `qgu.io`）
- 数据源：魁省 **Régie de l'énergie** 官方 GeoJSON（`regieessencequebec.ca/stations.geojson.gz`）+ **官方每周 Bulletin PDF**（零售毛利/区域均价）；
  抓取由 **本机 15 分钟探针 + Actions（外部 `repository_dispatch` + 小时兜底 cron）** 驱动
- 规模（2026-10-13 实测）：**2 462 个站点**、18 区、三油品；regular **171.9 / 中位 192.9 / 239.3**；快照 `generated_at` 16:55Z
- 多语言：法语（默认）/ 英语 / 简体中文；无后端、无账号、无追踪、无广告

## 3. 优势（为什么魁省司机愿意用）

1. **地图上直接看到价格 + 筛选真实作用到地图**——Protégez-Vous 点出官方平台"无法筛选、只能逐个 hover"（最硬差异）。
2. **官方"贵不贵"口径齐全**：Régie 每周零售毛利（#49）+ 站级中位/分位（#34）；**区域=范围**语义（#60）。
3. **打开即用、无广告、可安装**：竞品 App 近 50 条评论里 11–13 条在骂广告。
4. **数据诚实性 + 个人数据自持**：无合成/外推、覆盖门控、离线标注、无效坐标不冒充、卡片与快照一致、引用不静默失联（#65）、导出/导入 + CSV。
5. **没有后端也能做决策工具**：搜索/收藏/关注/排行/油费/日志/基准/距离排序，全部本地；三语；零运维。

## 6. 上游数据实测（2026-09-17 完成，避免重复调研）

- 站点 GeoJSON 属性只有 `Name, brand, Status, Address, PostalCode, Region, Prices[{GasType, Price, IsAvailable}]`：
  ❌ 无站点 ID、❌ 无 city、❌ 无单站更新时间、❌ 无服务设施；`IsAvailable=false` ⟺ 价格为空。
- metadata 的 `excel_url` XLSX 字段与 GeoJSON 相同 → 无收益，不接入。
- 区名匹配（2026-10-03 核对）：`normalizeText()` 能匹配周报的 en dash/无重音写法；只有 `Municipalités hors MRC \ CMM`（1 站）无对应行。
- **（2026-10-13 新增）平台公开接口排查**：`regieessencequebec.ca` 的 JS 包（`/assets/js/index-*.js`，仅 3.5 KB 加载器）内无 API 路径；
  `/api`、`/api/stations`、`/api/v1/stations`、`openapi.json`、`swagger.json`、`/data/stations.geojson` 全部 **404** →
  Reddit 所说"公共 API"应指我们已在用的 `stations.geojson.gz`；**没有可用的单站更新时间来源**。

## 9. 本轮提案（已建 issue）

**侧栏列表行可用键盘操作（`role="button"` + `tabindex` + Enter/Space + 焦点样式）** → issue **#88**（`pm-proposal`）。
为什么选它：这是当前**唯一客观、无争议**的功能性缺口（WCAG 2.1 A 级 2.1.1/4.1.2），
而其余候选都更弱或有更大风险：深色模式属"纯外观偏好"（筛检员的 REJECT 项之一）、
"价格+距离综合排序"与我自己的量化结论（中位收益 0）有张力、favorites 坐标键（#59 STEP 2）涉及跨模块迁移且 #87 尚未落地。
范围：`js/stats.js`（行语义与键盘处理）、`css/style.css`（`:focus-visible` 样式）、`tests/app.spec.js`（新增用例）——**3 文件、约 120 行**，additive，不动默认渲染。

## 10. 已评估但不建议 / 待提（避免重复提议）

- **深色模式**：仅 1 条评论明确要求；属筛检员列明的"纯外观偏好"风险 → 暂不提。
- **"价格 + 距离综合排序"（竞品 parity）**：需先定权重/系数与"估算而非承诺"的文案，并正面处理我自己的量化结论 → 暂缓（§11）。
- **favorites 坐标键（#59 STEP 2/3）**：跨模块存储语义 + 幂等迁移 + 备份兼容 → 等 #87 落地后单独提案。
- **"明日预测"**：竞品已做；我们坚持不预测（样本不足 + 失真风险）。
- **分享/深链 / App Clip 等价物**：无直接用户证据 → 暂缓。
- **站点级 1A rollup / 月粒度降采样**：先看体积与价值（§4）。
- **加油日志 L/100 km（里程表）**：超出边界且需处理部分加油/漏记 → 暂缓。
- **每日 `composantes`（每 MRC 一个 PDF）/ `rqe.pdf`**：成本与增量收益不划算 → 不接入。
- **抓取触发频率**：外部触发器已接线，仅剩 owner 侧配置；**探针常驻期间新鲜度已达标**。
