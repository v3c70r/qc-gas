# Régie weekly Bulletin — official retail margin & regional averages

Competitors answer "is this price fair?" with an official cost/margin framing
(gasquebec's *prix juste*, CAA's *prix réaliste*). Until #49 we only had our own
reconstructed regional benchmark (#34), i.e. no *official* margin story at all.

This document describes the integration of the Régie de l'énergie **weekly
Bulletin**, which gives us exactly that: per administrative region, the official
average pump price and the *estimated retail margin before sales taxes*.

## Source

- Fixed URL: `…/consommateurs/informations-pratiques/prix-petrole/publications/Publications-hebdomadaires/Bulletin/bulletin.pdf`
  (see `BULLETIN_URL` in `scripts/fetch_bulletin.py`)
- One PDF, generated by Microsoft Excel → the text layer is clean, so
  `pdftotext -layout` yields a usable column-aligned table. No OCR, no scraping,
  no third-party service.
- Contents used by us:
  - **Tableau 1 / 2 / 3** — regular / super / diesel, 17 regions:
    previous-week mean, current-week mean, week-over-week change and
    **Marge de détail estimée (hors taxes)**.
  - **Tableau 4** — Montreal minimum rack ("rampe de chargement") price by week
    (regular / super / diesel / mazout léger).

The daily `composantes` (one PDF per MRC, ~100 files/day) and the daily
`rqe.pdf` were evaluated and deliberately **not** integrated: too heavy on
upstream / no incremental value over our own finer per-station snapshot.

## Pipeline

| Piece | File | Role |
| --- | --- | --- |
| Fetcher + parser | `scripts/fetch_bulletin.py` | conditional GET, `pdftotext -layout`, parse, write |
| Offline tests | `scripts/test_fetch_bulletin.py` | parses a committed text fixture |
| Text fixture | `scripts/fixtures/bulletin-2026-09-28.txt` | real `pdftotext -layout` output |
| Output | `data/regie-margin.json` (+ `.br`) | consumed by the frontend |
| Workflow | `.github/workflows/update-data.yml` | installs `poppler-utils` if needed, runs the fetcher |

### Upstream etiquette

1. The step is wired behind the existing adaptive gate (`steps.gate.outputs.due`),
   so it only runs on the runs already allowed to poll upstream.
2. The request is **conditional** (`If-None-Match` + `If-Modified-Since`, taken
   from the validators stored in the previous file). The Bulletin is a *weekly*
   publication, so an unchanged Bulletin yields `304 Not Modified` and no bytes
   are transferred. An explicit guard also skips the request entirely once a
   full download has already happened on the same UTC day, so upstream sees **at
   most one download per day** (in practice ≈ one per week).
3. When the parsed payload is byte-for-byte identical the file is **not**
   rewritten, so an unchanged week produces **no new data commit**.
4. Any failure (network error, missing `pdftotext`, bad parse) keeps the previous
   file untouched and exits `0`; the workflow step uses `continue-on-error` like
   its neighbours, so a Régie outage never breaks the data run.

## Schema

```jsonc
{
  "v": 1,
  "generated_at": "2026-10-03T12:00:00Z",
  "source_url": "https://www.regie-energie.qc.ca/…/bulletin.pdf",
  "week": { "start": "2026-09-21", "end": "2026-09-28", "published_at": "2026-10-02" },
  "fuels": {
    "regular": {
      "regions": {
        "Montréal": { "prev_mean": 199.6, "mean": 197.0, "delta": -2.7, "margin": 1.4 },
        "Nord-du-Québec": {
          "prev_mean": 207.4, "mean": 211.1, "delta": 3.7, "margin": 13.4,
          "sub": {
            "Jamésie": { "prev_mean": 207.4, "mean": 211.1, "delta": 3.7, "margin": 13.4 },
            "Nunavik": { "prev_mean": null, "mean": null, "delta": null, "margin": null }
          }
        }
      },
      "quebec": { "prev_mean": 193.8, "mean": 192.0, "delta": -1.8, "margin": -0.6 }
    },
    "super": { "regions": { }, "quebec": { } },
    "diesel": { "regions": { }, "quebec": { } }
  },
  "rack": [
    { "week": "2026-09-28", "regular": 143.6, "super": 160.1, "diesel": 229.3, "mazout": 212.1 }
  ],
  "source": { "etag": "\"…\"", "last_modified": "Fri, 02 Oct 2026 15:17:34 GMT", "fetched_at": "…" }
}
```

Field semantics:

- All prices and margins are **¢/litre**. `margin` is the Régie's
  *Marge de détail estimée (hors taxes)*: pump price without GST/QST minus the
  sum (also tax-excluded) of the minimum rack price, transport cost, federal
  excise tax, provincial fuel tax and operating costs.
- `n/d` (not available) → `null`, never `0`.
- `margin` **keeps its sign**: diesel margins are frequently negative, which is
  meaningful (the pump price barely covers supply costs) and is surfaced by the
  UI rather than hidden.
- `Nord-du-Québec` is a parent region whose value equals its **Jamésie** row. The
  `Nunavik` sub-row (largely `n/d`, excludes taxes differently) is stored
  separately under `sub` and never overwrites the region value.
- `week.start` / `week.end` are the two column dates of Tableau 1; the app labels
  the data with `week.end` ("semaine du 28 sept."). `published_at` is the footer
  publication date.
- `sub` only appears when the Bulletin has sub-rows.

## Frontend

| Piece | File | Role |
| --- | --- | --- |
| Loader + matcher | `js/regie.js` | `getRegionMargin(region, fuel)`, silent on failure |
| Trends dashboard | `js/dashboard.js` | sortable **Marge (Régie)** column + source/week note |
| Station card | `js/station-card.js` | region-level margin line under the same-day benchmark |
| Copy | `js/i18n.js` | fr / en / zh labels + explanatory tooltip |

Region-name matching reuses `normalizeText()` from `js/search.js`, so
`Gaspésie–Iles-de-la-Madeleine` (en dash, no accent on *Iles*) matches our
`Gaspésie-Îles-de-la-Madeleine`, and `Saguenay–Lac-Saint-Jean` matches
`Saguenay-Lac-Saint-Jean`.

Deliberate UI rules:

- The card line is explicitly **regional** and dated with the bulletin week so it
  can never be mistaken for the station's own margin.
- A **negative** margin is shown with its sign and an explanatory tooltip;
  it is not simplified into "cheaper is better".
- `Municipalités hors MRC \ CMM` does not exist in the Bulletin → the margin row
  is **not rendered at all** there (no `0`, no `NaN`, no fabricated value).
- If the file is missing or fails to load, both surfaces hide the margin
  entirely and never throw.

## Update cadence

The Bulletin is a weekly publication (usually published Friday). Because the
workflow only rewrites the file when the payload changes, the repository gains
one tiny commit per week at most, plus a fresh `data/regie-margin.json.br`.
